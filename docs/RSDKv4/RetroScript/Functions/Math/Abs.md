# Abs

Gets the absolute number of `value`.

## Parameters

`value`

:   Variable from where to read the value.

## Return Value

Updates `value` with the result.

## Syntax

```
Abs(var value)
```

## Example

```
temp0 = -10
Abs(temp0) // temp0 is now positive 10

temp0 = 120
Abs(temp0) // temp0 is left unaffected and remains 120
```
